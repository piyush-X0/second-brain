# Second Brain — Backend

Built a personal knowledge management REST API to solidify backend fundamentals.

## What I built

- User auth (signup / signin) with JWT
- CRUD for content
- Tag system with auto findOrCreate logic
- Rate limiting with per-route independent counters

## Stack

Node.js · TypeScript · Express · MongoDB · Mongoose · JWT · express-rate-limit
